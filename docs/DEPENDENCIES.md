# 发布范围与外部依赖

本次发布包括视觉与路径求解、触屏应用、双串口执行器、写字机独立控制端、自定义辅助固件及可获得的仿真源码。所有展示名称采用中性表述，不使用设备销售商名称、商标图案或宣传素材。

屏幕驱动已在独立仓库发布，因此通过外部目录加载，不在这里重新打包。其仓库 URL 是技术依赖定位信息，不表示品牌背书。

未发布：原厂桌面程序、安装包、JAR/DLL、字体和字形库、解密产物、授权数据、逆向分析工具、硬件手册扫描件、串口抓包、设备日志、旧备份及开发者本地环境。经挑选的现场图片与两段成功演示视频另见 [现场展示](FIELD_DEMOS.md)，视频已清除定位和拍摄设备元数据。

芯片型号、通信协议与 Python 库名是复现所需的技术标识。去品牌化不能通过删除第三方版权声明实现；本次以不捆绑厂商 SDK、模板和媒体资源避免误授权。使用外部依赖时仍需遵守各自许可。

`pybullet/puzzle_device` 的代码引用历史 `assets/`。原始场景纹理与照片未发布，因此相应仿真入口需要自行准备场景文件，不属于开箱可用范围。实机的当前触屏入口不需要调用这些仿真资产。
